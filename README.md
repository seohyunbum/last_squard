# 라스트 스쿼드 (Last Squad)

> **정본 저장소:** [seohyunbum/last_squard](https://github.com/seohyunbum/last_squard)
>
> 과거 `YUNU_GAME/claude/last-war-game-copy-7dqved` 브랜치는 이관 원본으로 동결했다. 새 기능과 모바일 Claude 작업은 이 저장소에서만 진행한다.

아이와 함께 만드는 **라스트워 스타일 레인 러너** — 부대 뒤 어깨 시점(광고에서 보던 그 앵글)으로 도로를 달리며
게이트(`×2`, `+12`, `÷2`, `−6`)를 골라 병력을 불리고, 몰려오는 고철 로봇 군단을 자동 사격으로 막아내
구역 끝의 대장 로봇을 부순다.

> 전체이용가 감각: 상대는 눈·표정 없는 **고철 로봇**만 등장한다. 사람·동물 상대·유혈 없음.

## 실행

- **가장 쉬운 방법**: `index.html` 더블클릭 (설치도 빌드도 필요 없다)
- Windows: `launch-game.bat` 더블클릭
- 개발용 서버: `npm start` → http://localhost:5180
- **한 파일로 묶어 공유**: `npm run build` → `dist/last-squad.html` (이 파일만 보내도 그대로 실행된다)

## 핸드폰에 앱으로 깔기 📱

배포 주소를 폰 브라우저로 연 뒤 홈 화면에 추가하면, 앱 아이콘으로 열리고 주소창 없이 전체 화면으로 뜬다.
한 번 열어 두면 **인터넷이 끊겨도 실행된다** (차 안, 비행기 안).

- **아이폰 (사파리)**: 공유 버튼 → `홈 화면에 추가`
- **안드로이드 (크롬)**: 메뉴 `⋮` → `앱 설치` 또는 `홈 화면에 추가`

앱스토어 등록은 필요 없다. 설치용 파일은 `web/` 에 있고 `build-pages.js` 가 배포본에 함께 실어 보낸다.

| 파일 | 하는 일 |
| --- | --- |
| `web/manifest.webmanifest` | 앱 이름 · 아이콘 · 세로 고정 · 전체 화면 |
| `web/sw.js` | 오프라인 실행. 캐시 이름에 배포 커밋이 박혀서 새로 배포하면 저절로 갱신된다 |
| `web/icons/` | 홈 화면 아이콘 4종 (안드로이드 마스커블 · 아이폰용 포함) |

새로 배포한 내용은 **앱을 두 번째로 열 때** 반영된다 (한 번은 캐시로 바로 띄우고, 그 사이 새 파일을 받아 둔다).

## 그래픽 (3D)

**WebGL 로 진짜 3D 로 그린다** (`src/render3d.js`, Three.js r150 을 `vendor/` 에 넣어 오프라인으로 쓴다).
원근 카메라·방향광 그림자·거리 안개·발광 연출이 들어간다. 부대는 캡슐 병사, 게이트는 에너지 벽,
드럼통은 원통, 대장 로봇은 붉은 눈의 금속 덩치로 나온다.

- **WebGL 이 없거나 Three.js 를 못 받으면 기존 2D 렌더러로 자동 전환된다.** 구형 기기·차단 환경에서도
  게임은 그대로 돌아간다 (브라우저 smoke 가 두 경로를 모두 검사한다).
- 프레임이 계속 느리면 **그림자를 끄고 해상도를 낮춰** 스스로 가벼워진다.
- 언리얼 엔진은 쓸 수 없다 — 브라우저에서 파일 하나로 도는 게임이고, UE5 는 웹 빌드 경로가 없다
  (HTML5 지원 종료, 픽셀 스트리밍은 GPU 서버 필요). 그래서 WebGL 로 3D 를 직접 구현했다.

## 진행 구조

- **11구역 × 3챕터 = 33챕터.** 챕터를 깨면 다음 챕터가 열린다.
- **1·2챕터**는 코스 끝까지 버티면 돌파. **3챕터**는 그 구역의 **대장 로봇**을 잡아야 돌파다.
  구역 안에서도 챕터마다 조금씩 어려워진다.
- **33챕터를 모두 깨면 최종 결전**(👑 고철 군단 심부)이 열린다. 마지막 대장 로봇은 11구역
  대장보다 1.7배 단단하고 코스도 길다.
- **최종 결전을 깨면 엔딩**이 나온다 — 깬 챕터·모은 별·버티기 기록을 함께 보여준다.
- **최종 보스는 패턴이 네 개**다. 체력이 줄면 쓸 수 있는 패턴이 늘고, 같은 단계에서는 정해진 순서로
  돌아서 아이가 외워 대응할 수 있다. 시작할 때 이름을 크게 알려 준다.
  | 패턴 | 대응 |
  | --- | --- |
  | 부하 소환 | 몰려오는 부하를 정리한다 |
  | 부채꼴 사격 | 볼트가 도로를 덮지만 **한 칸은 비어 있다** — 그 구멍으로 |
  | 돌진 | 겨냥 동작 뒤에 달려든다 — 옆으로 피한다 |
  | 좌우 난사 | 볼트를 훑는다 — 훑는 방향 앞으로 달린다 |
- 챕터 하나는 20~40초쯤. 아이가 한 번에 한 챕터씩 끊어 놀 수 있는 길이다.

## 게임 규칙

1. **게이트가 실력이다.** 문 두 개 중 하나만 통과한다. 문에 적힌 연산이 병력 수에 그대로 적용된다
   (`×2`, `+12`, `÷2`, `−6`). 미리보기 숫자는 없다 — 직접 계산해서 고른다.
2. **병력 = 화력.** 병력이 많으면 총알 수와 피해량이 함께 오른다. 대신 진형이 넓어져 **피하기 어려워지고**,
   부딪힐 때 잃는 병력도 커진다. 무조건 불리기만 하면 되는 게 아니다.
3. **적 로봇**은 앞에서 걸어 내려온다. 쏴서 부수거나 옆으로 비켜 흘려보낸다. 부딪히면 병력을 잃는다.
   - 잡병(회색) · 돌격형(주황, 빠름) · 중장형(큰 놈, 많이 잃는다) · 사격형(보라, 원거리 볼트)
4. **바리케이드**는 쏴서 부수거나 피해서 지나간다. 그냥 박으면 크게 잃는다.
5. **드럼통 위의 총**: 드럼통 몸통에 **남은 타격 횟수**가 적혀 있다. 그 수만큼 맞히면(맞을 때마다 숫자가
   줄어든다) 터지고 위에 얹힌 총이 노면에 떨어진다. 그 위를 지나가면 일정 시간 **연사가 빨라진다**
   (겹쳐 먹으면 최대 3중첩, HUD에 남은 시간 표시). 화력 강화와 무관하게 **한 발 = 한 번**이라 세면서 쏠 수 있다.
   1구역은 3번, 후반으로 갈수록 6번까지 늘어난다. 안 터뜨리고 박으면 병력만 잃고 총도 놓친다.
6. **미니건 병사 (아군)**: 길에 서서 손을 흔들며 기다린다. 지나가면 **합류해서 함께 쏜다.**
   병력 수와 무관하게 자기 화력(한 발 8 × 화력 강화)을 초당 10발씩 쏟아서, 병력이 적을 때 특히 강하다.
   **게이트 연산(`×0`·`÷2`)에 영향받지 않는다** — 한 번 합류하면 그 챕터 끝까지 함께 싸운다.
   최대 3명(HUD에 🔫 표시), 이미 꽉 찼으면 부품으로 바뀐다. 대장 로봇이 있으면 비스듬히 조준한다
   (진형 바깥에 서 있어서 곧게만 쏘면 가운데 있는 대장을 스쳐 지나가기 때문).
7. **페이크 게이트 (`×0`)**: 3구역부터 **초록색인데 실제로는 손해인 문**이 나온다. 거짓은 색뿐이고
   문에 적힌 연산은 언제나 정직하다. **색이 아니라 숫자를 읽어야 한다.** 구역당 최대 하나,
   첫 게이트에는 절대 안 나온다.
8. **둘 다 초록인 게이트**: 양쪽 다 진짜 이득이지만 **한쪽이 더 크게 이득**이다. `+8` 과 `×2` 처럼
   병력 수에 따라 정답이 뒤집히는 짝이라(6명이면 더하기, 20명이면 곱하기) 한쪽으로 외울 수 없다.
   구역당 최대 2개, 페이크와는 겹치지 않는다.
9. **구역의 3챕터 끝은 대장 로봇.** 전진이 멈추고 정면 싸움이 된다. 부하를 계속 뽑고 볼트를 쏘며 다가온다.
10. **보상**: 부품(🔩)으로 시작 병력·화력·연사·기동력·부품 회수를 영구 강화한다. 별은 *최대로 불린 병력 대비
   생존 비율*로 준다 (60% 이상 ★3, 30% 이상 ★2).
11. 진행 상황(챕터·별·부품·강화)은 브라우저에 자동 저장된다. 예전 세이브는 챕터 단위로 자동 환산된다.

## 버티기 모드 🛡️

기지 화면의 **버티기** 버튼. 구역 모드와 부품·강화를 공유하지만 규칙이 다르다.

- **부대는 제자리에서 버틴다.** 끝도 보스도 없고, 죽을 때까지 이어진다.
- **왼쪽에서 문이 하나씩** 무작위로 내려온다. 짝이 없으니 *들어갈지 피할지*를 고른다.
  문 폭 안에 서 있을 때만 적용된다 — 비켜 있으면 아무 일도 없다. 숫자는 작게 나와서(`+7`, `÷2`)
  다가오는 동안 읽고 판단할 수 있다.
- **오른쪽에서 드럼통이 굴러온다. 깔리면 즉사** — 병력이 남아 있어도 그 자리에서 끝난다.
  적힌 횟수만큼 맞혀 터뜨리면 총이 떨어지고, 못 터뜨리면 왼쪽으로 피해야 한다.
- **병력 상한 60명.** 진형이 도로를 막을 만큼 커지면 즉사를 피할 방법이 없어지기 때문이다.
- 점수는 **버틴 시간**(★2 60초 · ★3 150초). 최고 기록은 기지 화면에 남는다.
  구역 해금·별은 건드리지 않는다.

## 코드 지도

| 경로 | 역할 |
| --- | --- |
| `index.html` | 캔버스 + DOM HUD/화면. 스크립트 로드 순서가 곧 의존 순서 |
| `src/config.js` | **밸런스 정본** — 숫자를 만지려면 여기만 고친다 |
| `src/util.js` | 클램프·보간·시드 난수·충돌 |
| `src/squad.js` | 병력 수 → 진형·화력·판정 폭 · 미니건 병사 (순수 로직) |
| `src/gates.js` | 게이트 연산·라벨 · 문 한 쌍(구역) · 문 하나(버티기) 생성 |
| `src/stage.js` | 챕터 코스 생성 (시드 고정 → 같은 챕터는 항상 같은 코스) · 최종 결전 |
| `src/survival.js` | 버티기 모드의 끝없는 코스 — 필요한 만큼 앞을 이어 붙인다 |
| `src/run.js` | 전투 상태 기계 — 캔버스·DOM 을 전혀 모른다 |
| `src/boss.js` | 최종 보스 패턴 상태 기계 (소환·부채꼴·돌진·난사) |
| `src/render3d.js` | **3D 렌더러 (WebGL/Three.js)** — 기본 경로 |
| `src/render.js` | 2D 폴백 렌더러 — WebGL 이 없을 때 쓰인다 |
| `vendor/three.min.js` | Three.js r150 (오프라인·빌드 없이 쓰려고 저장소에 둔다) |
| `src/fx.js` | 떠오르는 큰 숫자 연출 (뷰 전용, 게임 규칙 아님) |
| `src/ui.js` | DOM 화면·HUD (게임 규칙 없음, 콜백만) |
| `src/upgrades.js` · `src/save.js` | 영구 강화 정의 · localStorage 세이브 |
| `src/audio.js` | WebAudio 효과음 (오디오 파일 없음) |
| `src/main.js` | 지휘자: 입력·루프·화면 전환 배선만 |

## 검증

```bash
npm run verify       # 단위 테스트 + 자동 플레이 난이도 점검
npm run verify:full  # 위 + 실제 브라우저 smoke (스크린샷은 .smoke/)
npm run balance 4    # 강화 레벨 4 기준 1~10구역 자동 플레이 결과표
```

`npm run balance` 는 **"게이트를 잘 고르면 이기고, 가운데로만 달리면 진다"** 를 자동으로 확인한다.
밸런스 숫자를 바꾼 뒤에는 이 표로 난이도 곡선을 확인한다.

## 다음에 붙이면 재미있을 것

- 병력 종류(방패병·유탄병) 추가 — `config.js` 의 `squad` 와 `run.js` 의 `fire()` 확장

- 기지 화면에 부대 커스터마이즈(색·헬멧) — `render.js` 의 `drawUnit`
- 카메라 앵글 조정 — `config.js` 의 `camera` (`height` 를 낮추면 더 어깨 뒤 시점이 된다)
