# 라스트 스쿼드 (Last Squad)

아이와 함께 만드는 **라스트워 스타일 레인 러너** — 부대 뒤 어깨 시점(광고에서 보던 그 앵글)으로 도로를 달리며
게이트(`×2`, `+12`, `÷2`, `−6`)를 골라 병력을 불리고, 몰려오는 고철 로봇 군단을 자동 사격으로 막아내
구역 끝의 대장 로봇을 부순다.

> 전체이용가 감각: 상대는 눈·표정 없는 **고철 로봇**만 등장한다. 사람·동물 상대·유혈 없음.

## 실행

- **가장 쉬운 방법**: `index.html` 더블클릭 (설치도 빌드도 필요 없다)
- Windows: `launch-game.bat` 더블클릭
- 개발용 서버: `npm start` → http://localhost:5180

## 조작

| 무엇 | 어떻게 |
| --- | --- |
| 좌우 이동 | 마우스 드래그 · 화면 터치 · `←` `→` (또는 `A` `D`) |
| 사격 | 자동 (병력이 많을수록 화력이 세진다) |
| 소리 끄기 | `M` |
| 기지로 나가기 | `Esc` |

## 게임 규칙

1. **게이트가 실력이다.** 문 두 개 중 하나만 통과한다. 문에 적힌 연산이 병력 수에 그대로 적용되고
   (`×2`, `+12`, `÷2`, `−6`), 문 아래에 통과 후 병력 수가 미리 표시된다.
2. **병력 = 화력.** 병력이 많으면 총알 수와 피해량이 함께 오른다. 대신 진형이 넓어져 **피하기 어려워지고**,
   부딪힐 때 잃는 병력도 커진다. 무조건 불리기만 하면 되는 게 아니다.
3. **적 로봇**은 앞에서 걸어 내려온다. 쏴서 부수거나 옆으로 비켜 흘려보낸다. 부딪히면 병력을 잃는다.
   - 잡병(회색) · 돌격형(주황, 빠름) · 중장형(큰 놈, 많이 잃는다) · 사격형(보라, 원거리 볼트)
4. **바리케이드**는 쏴서 부수거나 피해서 지나간다. 그냥 박으면 크게 잃는다.
5. **구역 끝은 대장 로봇.** 전진이 멈추고 정면 싸움이 된다. 부하를 계속 뽑고 볼트를 쏘며 다가온다.
6. **보상**: 부품(🔩)으로 시작 병력·화력·연사·기동력·부품 회수를 영구 강화한다. 별은 *최대로 불린 병력 대비
   생존 비율*로 준다 (60% 이상 ★3, 30% 이상 ★2).
7. 10구역을 넘기면 **무한 전선**이 이어진다. 진행 상황은 브라우저에 자동 저장된다.

## 코드 지도

| 경로 | 역할 |
| --- | --- |
| `index.html` | 캔버스 + DOM HUD/화면. 스크립트 로드 순서가 곧 의존 순서 |
| `src/config.js` | **밸런스 정본** — 숫자를 만지려면 여기만 고친다 |
| `src/util.js` | 클램프·보간·시드 난수·충돌 |
| `src/squad.js` | 병력 수 → 진형·화력·판정 폭 (순수 로직) |
| `src/gates.js` | 게이트 연산·라벨·문 한 쌍 생성 |
| `src/stage.js` | 구역 코스 생성 (시드 고정 → 같은 구역은 항상 같은 코스) |
| `src/run.js` | 전투 상태 기계 — 캔버스·DOM 을 전혀 모른다 |
| `src/render.js` | 원근(의사 3D) 렌더러 — `run` 상태를 읽어 그린다 (상태를 바꾸지 않는다) |
| `src/fx.js` | 떠오르는 큰 숫자 연출 (뷰 전용, 게임 규칙 아님) |
| `src/ui.js` | DOM 화면·HUD (게임 규칙 없음, 콜백만) |
| `src/upgrades.js` · `src/save.js` | 영구 강화 정의 · localStorage 세이브 |
| `src/audio.js` | WebAudio 효과음 (오디오 파일 없음) |
| `src/main.js` | 지휘자: 입력·루프·화면 전환 배선만 |

## 검증

```bash
npm run verify       # 단위 테스트 + 자동 플레이 난이도 점검
npm run verify:full  # 위 + 실제 브라우저 smoke (스크린샷은 .smoke/)
npm run balance 4    # 강화 레벨 4 기준 1~10구역 자동 플레이 결과표
```

`npm run balance` 는 **"게이트를 잘 고르면 이기고, 가운데로만 달리면 진다"** 를 자동으로 확인한다.
밸런스 숫자를 바꾼 뒤에는 이 표로 난이도 곡선을 확인한다.

## 다음에 붙이면 재미있을 것

- 병력 종류(방패병·유탄병) 추가 — `config.js` 의 `squad` 와 `run.js` 의 `fire()` 확장
- 게이트에 새 연산(`^2`, 병력 종류 변환) — `gates.js` 의 `apply`/`makePair` 만 고치면 된다
- 기지 화면에 부대 커스터마이즈(색·헬멧) — `render.js` 의 `drawUnit`
- 카메라 앵글 조정 — `config.js` 의 `camera` (`height` 를 낮추면 더 어깨 뒤 시점이 된다)
